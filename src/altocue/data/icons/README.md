# Badge icons

`tabler.json` holds the outline icons the `feature_badge` format draws.

- **Source:** [Tabler Icons](https://github.com/tabler/tabler-icons), outline set, version 3.35.0, read from the published npm package `@tabler/icons`.
- **Licence:** MIT. The notice, copyright 2020-2025 Paweł Kuna, is in `LICENSE` beside this file and must travel with it.
- **Changes:** only the path data is kept, one list per icon, with each file's empty bounding path left out. The shapes are unchanged.
- **Drawn in code:** `waveform` and `clip-cut` are original, written in `src/altocue/motion/formats/film.py`. They are not Tabler's.
- **Adding one:** copy its paths from the same release, and keep the version above true.
