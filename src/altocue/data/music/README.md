# Music stings

Four short CC0 stings, stereo, 48 kHz Ogg Opus, each under 40 KB. `tracks.json` holds the same table for `altocue music`.

Nobody has listened to these. They were chosen by file name and measured length, so hear them before you ship anything.

The longest file in the pack lasts 1.76 seconds, so these suit an ending or a cue. The mix loops music to the length of the film, and a loop this short is heard as one.

| File | Use | Length | Source file | Pack |
|---|---|---:|---|---|
| `jingle-sax.ogg` | A short sax sting | 1.74 s | `jingles_SAX07.ogg` | [Music Jingles](https://kenney.nl/assets/music-jingles) |
