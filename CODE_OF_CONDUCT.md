# Code of conduct

Altocue is a small project and we want it to be an easy place to work.

- **Be kind and be specific.** Criticise the code, not the person.
- **No harassment.** No insults, discrimination, sexual content or personal attacks, in any form.
- **Respect a no.** If someone asks you to stop, stop.

These rules apply in issues, pull requests and anywhere you speak for the project.

## Reporting

Report a problem privately through the [Stratos House website](https://www.stratosagency.ai), or use GitHub's "Report abuse" on the content. Maintainers may edit or remove content, or block anyone who breaks these rules.
