# Altocue

Altocue edits raw footage into finished video on this machine, and makes launch films and explainers with no footage.

- Start with the `altocue_doctor` tool. If Altocue is missing, ask the user, then call `altocue_install` with `confirm` true.
- Read `altocue_guide` with topic `altocue` before editing. It holds the workflow and the hard rules. Each tool has its own guide: `altocue-cut`, `altocue-motion`, `altocue-launch` and more.
- Run commands with `altocue_run`. Long ones keep running in the background, and `altocue_job` follows them.
- Never spend money, upload footage or install software without the user's yes for that exact step.
